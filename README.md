# CONVERTIDOR

Aplicación de escritorio en Java desarrollada con NetBeans para realizar conversiones de unidades de longitud.

## Características

- Conversión de **Kilómetros a Millas**.
- Conversión de **Millas a Kilómetros**.
- Interfaz gráfica amigable utilizando Java Swing (`JFrame`).
- Opciones para limpiar los campos y realizar nuevos cálculos rápidamente.

## Requisitos

- Java Development Kit (JDK) 8 o superior.
- IDE compatible con proyectos NetBeans (NetBeans, Eclipse, IntelliJ, etc.).
